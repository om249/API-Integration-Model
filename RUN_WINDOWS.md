# Quick Run Guide — Windows

Open Command Prompt or PowerShell inside this project folder.

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python train_model.py
python app.py
```

Then open:

```text
http://127.0.0.1:5000
```

Click one of the example roles, or paste your own resume text and click **Predict Job Role**.
