# AI Resume Job Classifier — Task 2

A small AI prototype for **Task 2: Model or API Integration**.

The prototype integrates a machine-learning text classification pipeline using **scikit-learn**. It takes resume text and predicts one of five job categories:

- Software Developer
- Data Analyst
- Data Scientist
- Web Developer
- Java Developer

> This is a demonstration/assistive prototype. It should not be used as the sole basis for hiring decisions.

## 1. Problem

Recruiters and placement teams may need to organize many resumes by suitable job roles. This prototype demonstrates how an NLP classification model can assist with the initial categorization of resume text.

## 2. Technology

- Python
- Flask
- pandas
- scikit-learn
- TF-IDF Vectorizer
- Logistic Regression
- joblib
- HTML/CSS/JavaScript

No external API key is required.


## 5. Installation

### Step 1 — Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/AI-Resume-Job-Classifier.git
cd AI-Resume-Job-Classifier
```

### Step 2 — Create a virtual environment

Windows:

```bash

venv\Scripts\activate
```




## 7. API Example

The prototype exposes a simple prediction endpoint:

```http
POST /predict
Content-Type: application/json
```

Request:

```json
{
  "resume": "Python SQL Pandas Power BI Excel dashboard data visualization"
}
```

Response:

```json
{
  "predicted_role": "Data Analyst",
  "confidence": 90.0,
  "ranking": [
    {"role": "Data Analyst", "confidence": 90.0}
  ]
}
```

The actual confidence/ranking values are generated by the model at runtime.

## 9. Privacy and Responsible Use

The sample dataset contains synthetic/non-identifying resume descriptions. When using real resumes:

- Remove names, phone numbers, email addresses and addresses where they are not required.
- Do not expose personal data in GitHub.
- Do not use the prediction as an automated hiring decision.
- Evaluate the model for bias and performance across relevant populations before any real-world deployment.
