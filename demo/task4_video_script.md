# Task 4 — Final AI Application Demo Script

**Project: AI Resume Job Classifier**

## Introduction

Hello everyone! This is my Task 4 final AI application, the AI Resume Job Classifier. The project uses Python, Flask, and machine learning to predict potential job categories from resume-related text.

## Problem and Approach

The objective is to demonstrate how NLP and machine learning can assist with the initial organization of resumes. The model uses TF-IDF for text feature extraction and Logistic Regression for classification.

## Live Demonstration

First, I will enter a sample resume containing Python, SQL, Pandas, Power BI, and Excel skills.

The application returns a predicted job category and displays confidence, similarity to reference data, and relevant keywords.

Next, I will enter insufficient input and unrelated text to demonstrate the application's validation and warning behavior.

## Intelligent Features

The application includes input validation, technical-domain detection, confidence checking, reference similarity, prediction evidence, and error handling.

## Limitations and Responsible Use

This is an educational prototype trained on a small synthetic dataset. It has not been validated for real-world recruitment and must not be used as the sole basis for hiring decisions.

## Conclusion

This project brings together model integration, intelligent input analysis, a web interface, testing, and responsible-use documentation. Thank you for watching!
